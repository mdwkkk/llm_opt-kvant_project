# **Сравнение полного дообучения, LoRA и QLoRA при адаптации компактной языковой модели к классификации тональности русскоязычных твитов в условиях ограниченной видеопамяти**

# План научно-исследовательской работы

**Тема:** «Сравнение полного дообучения, LoRA и QLoRA при адаптации компактной языковой модели к классификации тональности русскоязычных твитов в условиях ограниченной видеопамяти»

## 1. Текущий этап: анализ научной литературы

На текущем этапе проведён предварительный анализ научной литературы по полному дообучению языковых моделей (*Full Fine-Tuning*), параметро-эффективному дообучению LoRA и QLoRA. Рассмотрены принципы работы методов, их преимущества и ограничения, а также существующие исследования, посвящённые сравнению качества моделей и вычислительных затрат. На основе анализа сформулированы цель исследования и предварительная гипотеза: **QLoRA позволит снизить потребление видеопамяти относительно LoRA при сохранении сопоставимого качества классификации.**

## 2. Подготовка экспериментального окружения

Следующий этап — подготовка экспериментального окружения и выбор данных. В качестве базовой модели планируется использовать компактную инструкционную языковую модель `Qwen2.5-0.5B-Instruct`, а для классификации тональности русскоязычных твитов — датасет [RuSentiTweet](https://github.com/sismetanin/rusentitweet). Предстоит проверить доступность и структуру данных, уточнить состав классов, сформировать обучающую, валидационную и тестовую выборки, а также настроить среду обучения на бесплатном облачном GPU.

## 3. План экспериментального исследования

В экспериментальной части планируется сравнить четыре основных варианта: исходную модель без дообучения, полное дообучение (*Full Fine-Tuning*), LoRA и QLoRA. Если полное дообучение окажется слишком ресурсоёмким для доступного оборудования, будут проверены возможные способы его запуска либо отдельно зафиксированы ограничения эксперимента.

Основными метриками качества станут **Macro-F1 и accuracy**. Вычислительные затраты будут оцениваться по времени обучения, пиковому потреблению видеопамяти и количеству обучаемых параметров. Дополнительно планируется исследовать влияние ранга LoRA на качество классификации.

## 4. Анализ результатов и подготовка статьи

На заключительном этапе предполагается провести сравнительный анализ полученных результатов, определить компромисс между качеством классификации и вычислительными затратами, сформулировать выводы и подготовить итоговый текст статьи. Особое внимание будет уделено воспроизводимости экспериментов: фиксации параметров обучения, версий библиотек, характеристик GPU и правил оценки. **Окончательные выводы и аннотация будут сформированы после получения экспериментальных результатов.**
